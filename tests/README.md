# Автопроверка цен

`check_prices.py` открывает калькулятор в браузере без окна (ставки — из `rates.dat` в этой папке, а не с сайта) и проходит три сценария:

1. **Расширенный режим:** деталь 80×60×40 мм во всех 5 технологиях (FDM, SLA, DLP, LCD, SLS) тиражом 1, 10 и 50 шт.
2. **Простой режим:** та же деталь с автоподбором принтера и положения, 1 и 10 шт.
3. **Заказ из двух деталей:** FDM ×10 и SLA ×5 (вторая — 30×30×20 мм) и оформленное КП: в смете 2 детали, итог КП равен итогу сметы, номер КП 2026-001.

Проверка не проходит, если:
- в `index.html` устарели метки версий `app.js?v=…` / `styles.css?v=…` — запустите `python tools/version.py` (без меток браузер клиента может взять старый `app.js` из кэша);
- на странице есть ошибки JavaScript;
- какая-то технология не выдала цену;
- цена отличается от эталона в `prices.json`;
- в заказе не 2 детали или КП не совпадает со сметой.

На GitHub проверка запускается сама при каждом изменении (вкладка Actions, «Проверка цен»).

## Если ставки меняли намеренно

Цены изменятся, и проверка покажет, какие именно: «было 24520 ₽, стало 25100 ₽». Если так и задумано, обновите эталон и закоммитьте его вместе со ставками:

```
python tests/check_prices.py --update
```

## Запуск на своём компьютере

```
pip install playwright
python tests/check_prices.py --chrome
```

`--chrome` берёт установленный Google Chrome, чтобы не скачивать отдельный браузер.
